## 代码使用教程

1.安装requirements.txt里的依赖项

```
pip install -r requirements.txt
```

2.在文件路径下安装playwright

```
playwright install
```

3.下载node.js

参考[Node.js安装及环境配置超详细教程【Windows系统】_windows 安装nodejs-CSDN博客](https://blog.csdn.net/Nicolecocol/article/details/136788200)，简单无坑，只要记得下载后加入环境变量即可

4.在文件路径下安装vue

```
npm install
```

5.运行代码：需要两个命令行窗口

```
python server.py
```

```
npm run dev
```
